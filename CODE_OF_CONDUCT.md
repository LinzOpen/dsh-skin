# Code of Conduct · 行为准则

## The short version

Be decent. Assume the other person is trying to help. Argue about the code, not the person.

好好说话。默认对方是想帮忙的。对事不对人。

## What's not okay

Harassment, personal attacks, discrimination, or sexualised content in any project space — issues,
pull requests, discussions, commit messages, and the skins themselves.

Skins are visual, and this project ships them under its own name. A skin that is sexually explicit,
hateful, or that targets a real person is out of scope regardless of its technical quality.

皮肤是视觉内容，而这个项目是署自己的名分发它们的。露骨的、仇恨的、或者针对某个真实个人的皮肤，
不管做得多好都不收。

## Enforcement

Maintainers will remove, edit, or reject contributions that don't follow this, and may block accounts
that keep at it. To report something, use **GitHub → Security → Report a vulnerability** on this
repository (it's a private channel and works for conduct reports too) or open an issue if it's
already public and you're comfortable doing so.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), trimmed to what this
project can actually enforce.
